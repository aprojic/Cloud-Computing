# Contributing

Found a mistake or a step that doesn't work? Thank you, that helps everyone in the course.

## Report a problem

Open an issue and pick a form:

- **Problem with a lab**: a command fails, or the output differs from the instructions.
- **Typo or unclear step**: something is wrong, outdated or hard to follow.

Issues are **public**. Never paste passwords, keys, tokens or your full Azure subscription ID.
Questions about grades, submissions or deadlines go to Merlin or email, not here.

## Suggest a fix

1. Fork the repository and create a branch.
2. Make the change and open a pull request that explains what you changed and why.

A good fix to a lab instruction may be mentioned in class (with your permission).

## How lab instructions are written

Each lab is one folder with a `README.md`, written in English. The same file is turned into the PDF on Merlin, so please keep the conventions from [`.github/lab-template.md`](.github/lab-template.md):

| Use | For |
|---|---|
| `## Part N — Title · ~X min` | the parts of a lab, with a time estimate |
| `> [!NOTE]` + `**Expected output**` | what students should see |
| `> [!TIP]` | hints and common errors |
| `> [!IMPORTANT]` | what goes into the report |
| `> [!WARNING]` | anything that costs money or can't be undone |
